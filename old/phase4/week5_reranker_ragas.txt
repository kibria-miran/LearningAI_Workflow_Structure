DAY 1: RERANKER CONCEPT
Estimated: 45 min | Cost: $0.00
----------------------------------------------------------------

CONCEPT:
  Your current pipeline: query -> retrieve top-20 -> pass top-5 to LLM.
  A reranker adds a step: query -> retrieve top-20 -> RERANK -> pass top-4 to LLM.

  WHY RERANK?
  Embedding models (MiniLM) are fast but imprecise. They find
  "roughly relevant" chunks. A cross-encoder reranker is slower
  but more precise — it reads the query AND the chunk together
  and scores their relevance jointly.

  ANALOGY:
  Embedding search = a librarian who quickly scans book spines.
  Reranker = a librarian who reads the first page of each book.
  The second pass is slower but more accurate.

  WHEN RERANKERS HURT:
  Rerankers can hurt on exact identifier queries (order IDs,
  product codes). The cross-encoder may not understand that
  "ORD-4521" is more relevant than a paragraph about orders.
  Always test before keeping.

  OPTIONS:
  - Cohere Rerank API (paid, fast, high quality)
  - cross-encoder/ms-marco-MiniLM-L-6-v2 (free, local, slower)

  For this week: use the local cross-encoder (free).

  pip install sentence-transformers  # already installed

DAY 2: TRY THE RERANKER — MEASURE LATENCY
Estimated: 90 min | Cost: $0.00
----------------------------------------------------------------

CODE:
  # day2_reranker.py
  from sentence_transformers import CrossEncoder
  import time
  from day2_rrf import rrf_retrieve

  reranker = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2")

  def rerank(query: str, chunks: list[dict], top_n: int = 4) -> list[dict]:
      """Rerank chunks using cross-encoder. Returns top_n."""
      pairs = [(query, c["text"]) for c in chunks]
      scores = reranker.predict(pairs)
      ranked = sorted(zip(scores, chunks), key=lambda x: x[0], reverse=True)
      results = []
      for score, chunk in ranked[:top_n]:
          chunk = chunk.copy()
          chunk["rerank_score"] = float(score)
          results.append(chunk)
      return results

  # Compare with and without reranker
  query = "How do I set up a webhook in n8n?"

  start = time.time()
  dense_results = rrf_retrieve(query, k=5)
  dense_time = time.time() - start

  start = time.time()
  candidates = rrf_retrieve(query, k=20)
  reranked = rerank(query, candidates, top_n=4)
  rerank_time = time.time() - start

  print(f"Without reranker ({dense_time*1000:.0f}ms):")
  for r in dense_results:
      print(f"  {r['source']} p{r['page']}")

  print(f"\nWith reranker ({rerank_time*1000:.0f}ms):")
  for r in reranked:
      print(f"  {r['rerank_score']:.3f} | {r['source']} p{r['page']}")

DAY 4: RAGAS — FAITHFULNESS + ANSWER RELEVANCY
Estimated: 90 min | Cost: <$0.05
----------------------------------------------------------------

CONCEPT:
  RAGAS is an automated RAG evaluation framework.
  It uses an LLM to judge answer quality on two dimensions:

  FAITHFULNESS: Is every claim in the answer supported by the
  retrieved context? Score 0–1. Low score = hallucination.

  ANSWER RELEVANCY: Does the answer actually address the question?
  Score 0–1. Low score = off-topic answer.

  pip install ragas datasets

  NOTE: RAGAS makes LLM calls to judge answers. It costs money.
  Run it on a sample of 10–15 questions, not all 30.

CODE:
  # day4_ragas.py
  from ragas import evaluate
  from ragas.metrics import faithfulness, answer_relevancy
  from datasets import Dataset
  from day2_first_rag import rag_answer_with_guardrail
  from day1_retrieval import retrieve
  import yaml

  with open("tests/rag_eval.yaml") as f:
      eval_questions = yaml.safe_load(f)

  # Sample 10 answerable questions
  sample = [q for q in eval_questions if q["question_type"] != "refusal"][:10]

  data = {"question": [], "answer": [], "contexts": [], "ground_truth": []}

  for q in sample:
      result = rag_answer_with_guardrail(q["question"])
      chunks = retrieve(q["question"], k=4)
      data["question"].append(q["question"])
      data["answer"].append(result["answer"] or "")
      data["contexts"].append([c["text"] for c in chunks])
      data["ground_truth"].append(" ".join(q.get("key_facts", [])))

  dataset = Dataset.from_dict(data)
  scores = evaluate(dataset, metrics=[faithfulness, answer_relevancy])
  print(scores)

DAY 6: PROFILE — TIME PER STAGE
Estimated: 60 min | Cost: $0.00
----------------------------------------------------------------

CONCEPT:
  Profile each stage of your pipeline to find bottlenecks.
  You can't optimize what you haven't measured.

  STAGES TO PROFILE:
  1. Embed query (MiniLM)
  2. FAISS search
  3. BM25 search
  4. RRF merge
  5. Reranker (if kept)
  6. LLM call

CODE:
  # day6_profile.py
  import time
  from sentence_transformers import SentenceTransformer
  import faiss, numpy as np, json
  from rank_bm25 import BM25Okapi

  model = SentenceTransformer("all-MiniLM-L6-v2")
  index = faiss.read_index("phase4/results/faiss.index")
  with open("phase4/results/chunks_metadata.json") as f:
      chunks = json.load(f)
  tokenized = [c["text"].lower().split() for c in chunks]
  bm25 = BM25Okapi(tokenized)

  query = "How do I set up a webhook in n8n?"
  N = 10  # run N times for stable average

  stages = {}

  # Stage 1: Embed
  times = []
  for _ in range(N):
      start = time.time()
      vec = model.encode([query]).astype("float32")
      faiss.normalize_L2(vec)
      times.append(time.time() - start)
  stages["embed_query"] = sum(times) / N * 1000

  # Stage 2: FAISS search
  times = []
  for _ in range(N):
      start = time.time()
      index.search(vec, 20)
      times.append(time.time() - start)
  stages["faiss_search"] = sum(times) / N * 1000

  # Stage 3: BM25 search
  times = []
  for _ in range(N):
      start = time.time()
      bm25.get_scores(query.lower().split())
      times.append(time.time() - start)
  stages["bm25_search"] = sum(times) / N * 1000

  for stage, ms in stages.items():
      print(f"{stage:20s}: {ms:.1f}ms")
