DAY 1-2: JSONL TRACE
----------------------------------------------------------------

CONCEPT:
  One line per event, one file per run: traces/RUN_ID.jsonl.
  Without a trace, "the agent did something weird" is unfixable.

CODE:
  import json, time, uuid
  class Trace:
      def __init__(self):
          self.run_id = time.strftime("%Y%m%d-%H%M%S-") + uuid.uuid4().hex[:6]
          self.f = open(f"traces/{self.run_id}.jsonl", "a", encoding="utf-8")
      def log(self, kind, **data):
          self.f.write(json.dumps({"t": time.time(), "kind": kind, **data}, default=str) + "\n")
          self.f.flush()

  Events: model_call (messages count, tokens, cost, latency),
  tool_call (name, args), tool_result (result[:500], error?),
  guardrail (which one fired), final (success, answer, total cost).
